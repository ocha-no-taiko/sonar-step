# コンテンツ JSON の編集ガイド

ゲームの数値・曲・文言はすべてこのフォルダの JSON で管理しています。`_note` で始まるキーはメモ用なので、ゲームは読みません。

| ファイル | 中身 |
| --- | --- |
| `config.json` | BPM、各フェーズの小節数、難度（フレーズの再生回数）、ダメージ、基地HP、持ち越しのルール、視覚ヒント、スコア、音量 |
| `tracks.json` | トラック（= 音色 = 敵の種類）。HP、色、敵の形、シンセのパラメータ。並び順は盤面の手前→奥 |
| `song.json` | 曲。セクションごとの解放トラック、伴奏（ベースのリズムとコード）、ターンごとのフレーズと砲台の上限 |
| `texts.json` | 画面の文言。`{n}` の部分は実行時に差し込まれる |

## フレーズの書き方

`"kick": "x.......x......."` のように16文字で書きます。`x` が敵、`.` が空き。1文字 = 16分音符。
持ち越し敵の置き場所を残すため、1トラックの敵は8体までにしてください（テストで確認しています）。

## よくある調整

- **難しすぎる**: `song.json` の `turrets` を増やす、`config.json` の `bars.think` を増やす、`carry.carriedBonusTurrets` を 1 にする（持ち越し敵の分だけ砲台が増える）
- **イージーが長い**: `config.json` の `difficulties` で easy の `plays` を 4 にして、タイトルで視覚ヒントを ON にする運用もできます
- **フレーズ再生中も砲台を置けるようにしたい**: `placement.allowDuringPhrase` を true
- **持ち越し敵の歪みが強すぎる／弱すぎる**: `audio.distortion`（大きいほど歪む）と `audio.carriedGain`

変更したら `npm test` で確認してください（各ターンが砲台の上限内で全滅させられるかも検証します）。
