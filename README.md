# SONAR STEP

敵のフレーズを「聴いて」覚え、シーケンサーに砲台を「打ち込んで」迎撃する、リズム記憶パズル × タワーディフェンス。ゲームクリエイター甲子園向けのミニゲーム（1プレイ 3〜5分）。

**遊ぶ**: https://ocha-no-taiko.github.io/sonar-step/

## ルール

1. 敵の位置はフレーズ（音）で教えられる。
2. 聴いた位置に砲台を置く。ズレても隣のマスなら半分当たる。
3. 倒しきれなかった敵は赤くなって次のターンへ。2回目で基地に直撃する。

操作: マスをクリック（タップ）で砲台を置く／外す。`Space` で準備完了。

## ターンの流れ

`NEW TRACK`（新しい音色の紹介。解放時のみ）→ `READY`（4カウント）→ `LISTEN`（フレーズ再生。回数は難度で変わる）→ `BUILD`（シンキングタイム。置いた砲台はその音色で鳴る）→ `INCOMING`（敵の入場とダメージ判定）→ 結果

## 試作で決めた値（`src/content/*.json` で変更できる）

| 項目 | 値 |
| --- | --- |
| BPM / 盤面 | 120 / 4トラック × 16ステップ |
| ダメージ | パーフェクト 2、グッド 1（範囲は左右1ステップ、重なりは加算） |
| 敵HP | キック 2（大型）、スネア 2、ハイハット 1（ザコ）、カウベル 3（ボス級） |
| ターン数 | 8（INTRO → VERSE → BUILD-UP → DROP、各2ターン。1セクションごとにトラック解放） |
| 砲台の上限 | ターンごとに 3〜10（最少必要数 +1 前後） |
| シンキングタイム | 最大 8小節（準備完了で早送り。残り小節 × 20点のボーナス） |
| 基地HP | 5（2周目以降 3） |

仕様書に無く、自分で足したもの:

- シンキングタイム中、置いた砲台をそのトラックの音で鳴らす（耳で答え合わせ）。`config.json` の `thinking.playPlacedTurrets` で切れる
- 最終ターンで倒しきれなかった敵は持ち越し先がないので、そのまま基地に直撃
- 視覚ヒント（タイトルで切り替え）: フレーズ再生中、敵がいる「列」だけうっすら光る。トラックは耳で判断する
- 持ち越し敵の再配置は固定シード＋同じトラック内（公平さのため）

## 開発

```bash
npm install
npm run dev     # http://localhost:5191
npm test        # ルールとコンテンツの検証
npm run build
```

- `src/game/` ルールと進行（DOM・音に依存しない。`npm test` の対象）
- `src/audio/engine.js` Web Audio のシンセとステップ単位のスケジューラ（音声ファイルなし）
- `src/three/stage.js` Three.js の描画（ブルーム、パーティクル）
- `src/ui/hud.js` DOM の UI
- `src/content/` 数値・曲・文言の JSON（編集ガイドは `src/content/README.md`）

`main` に push すると GitHub Actions がテスト → ビルド → GitHub Pages へデプロイする。
